How these differ from asking a chat assistant

A chat assistant can do a version of all of this if you paste your material into it each time. The differences are narrow and worth stating precisely rather than overselling.

These run against everything you have already saved, without re-uploading it, and they are deterministic — the same sources give the same answer every time, and the answer can be recomputed and checked. Tracing a summary returns character offsets into the source rather than a description of where something came from, and conflicting figures are found by unit arithmetic, so the comparison is arithmetic rather than judgement.

For most one-off questions, a chat assistant is the faster tool and there is no reason to pretend otherwise.
